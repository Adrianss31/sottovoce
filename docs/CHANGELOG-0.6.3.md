# Sottovoce 0.6.3

- La home mantiene ferma la libreria quando avvii o metti in pausa un audiolibro.
- Il pannello di ascolto si compatta gradualmente mentre scorri, mantenendo i comandi compatti già presenti.
- Nella scheda del libro la copertina e i dettagli seguono lo scorrimento in entrambe le direzioni; il titolo mantiene un'altezza stabile durante il ridimensionamento.
